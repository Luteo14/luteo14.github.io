# LUTEO14 PRO V2.1 — Portail documentaire

## Livré
- 5 pages domaines et une page par prestation, issues des bullet points du site fourni.
- Espace documentaire prévu sur chaque prestation, sans exposition de fichiers privés.
- Page d’administration indiquant explicitement que l’authentification et l’upload ne sont pas encore actifs.
- Navigation responsive et palette bleu/rose.

## Sécurité
GitHub Pages est public : NE PAS y déposer de documents confidentiels. La connexion sécurisée et l’upload web exigent Cloudflare Access + Worker avec vérification des jetons + R2 privé + D1. Ce ZIP ne prétend pas activer ces services.

## Installation
Copier `pro/` et `README-PRO-V2.1.md` dans le dépôt existant, puis GitHub Desktop → Commit → Push. Ne pas remplacer le reste du site.
