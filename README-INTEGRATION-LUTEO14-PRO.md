# Mise à jour LUTEO14 Pro — domaines et navigation

Cette archive contient le dossier `pro/` à copier à la racine du dépôt LUTEO14. Elle ajoute la page d’accueil illustrée, les cinq pages de domaine et les pages de prestation associées.

## Installation
1. Sauvegarder le dossier `pro/` existant.
2. Décompresser cette archive à la racine du dépôt et accepter le remplacement du dossier `pro/`.
3. Publier le dépôt selon votre processus GitHub Pages habituel.

## Compatibilité
- Les routes historiques `/pro/formation/`, `/pro/accompagnement/`, etc. restent présentes.
- Les identifiants de catalogue et les paramètres envoyés à l’API documentaire conservent leurs valeurs existantes. Aucun changement de Worker n’est requis pour afficher le contenu public déjà configuré.
- Les cinq catégories sont éditoriales. Les prestations de « Gestion de projet » reprennent les trois intitulés du visuel ; les autres prestations sont réparties à partir du catalogue existant. Les textes génériques restent à valider et enrichir.
- Les illustrations sont des recadrages de l’image fournie.
