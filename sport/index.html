Confidentialité & consentement

Strava API

Le module demande l'accès en lecture à tes activités afin de les afficher dans ton dashboard personnel. Tu peux retirer ton consentement à tout moment avec le bouton « Déconnecter et supprimer ».

La déconnexion révoque les jetons côté Strava et supprime les jetons stockés côté backend. Le dashboard revient alors aux données locales du fichier JSON.

Important : les données récupérées par l'API Strava ne sont pas envoyées à un modèle d'IA par cette version.
